# Answer templates (Higher), by pattern

How to read this. Each pattern has: when it appears, a set-out skeleton (this project's own teaching advice, not Pearson wording), what each example scheme awards and its conditions (our own words, with scheme file and PDF page), common errors, and "seen in" counts from our data.

Evidence status: the marking lines describe only the listed example schemes; they are not general marking rules and other questions in the pattern may differ. The only examiner report covering Higher papers that we found is June 2019 (general chief examiner report), so common-error lines have an evidence id (T-number in `templates-evidence.csv`) or say none found. Skeleton steps are our teaching advice and are not scheme evidence. See `template-patterns.csv` for every question id per pattern.

Seen-in counts: "narrow" is the number of questions whose primary topic is in the pattern's topics and whose method note names the pattern; "broad" is all questions with that primary topic. Counts are of Higher questions, not de-duplicated against Foundation (the Foundation pass is not done).

## Solve linear equations

- Seen in: 5 questions (narrow), 6 (broad). Topics: A04.
- When it appears: A multi-step setting-up question (areas, perimeters) that ends in a linear equation, or a plain equation with fractions.
- Teaching advice (ours, set-out skeleton): 1 Write each quantity as an expression. 2 Form one equation. 3 Clear fractions or brackets first. 4 Collect terms in x on one side. 5 Solve and state the value. 6 Substitute back to check.

## Complete the square and turning point

- Seen in: 5 questions (narrow), 12 (broad). Topics: A06, A18.
- When it appears: Write in the form (x-a)^2+b, or find a turning point or maximum.
- Teaching advice (ours, set-out skeleton): 1 Take out the leading coefficient if it is not 1. 2 Halve the x coefficient, square it. 3 Write the squared bracket and correct the constant. 4 Read the turning point from the bracket and constant.
- What the example schemes show (each line is one scheme; conditions apply to that scheme only):

## Show that and Prove: set-out checklist

- Structure: define general quantities, work line by line, finish on the exact statement asked for, then state the conclusion in words. (Skeleton is own advice.)
- Final-line requirement: in the schemes read (nov2022-1h-16, jun2022-1h-12, jun2022-1h-13, jun2023-3h-20, nov2020-1h-21) the last mark is a communication mark for a complete argument or stated conclusion; a recurring-decimal proof with only terminating decimals scored no proof credit (jun2023-3h-20, scheme PDF p13-14).
- What loses marks: testing particular values instead of a general argument (T08, examiner report June 2019, 1h q13).
