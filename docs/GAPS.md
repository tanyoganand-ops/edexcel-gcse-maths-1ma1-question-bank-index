## Method note provenance and counts (24 Nov 2026, from the current JSON and CSV files)

Counts are taken from questions-foundation.json, questions.json and the three CSVs, and they agree:

- Foundation, 943 questions: 707 notes written from the full scheme entry (docs/foundation-method-notes.csv has exactly these 707 rows), and 236 inherited from a verified Higher twin (see alsoOn; the Foundation note is the same text as the Higher note, re-synced 24 Nov after the Higher edits). 707 + 236 = 943.
- Higher, 740 questions: each has its own note. Notes for 55 Higher questions were re-read against the scheme entry: 3 that had been reduced to a pointer plus 52 whose wording had depended on removed figures (the list is in the git history of this commit). nov2022-1h-12 keeps its short note; only its template line was corrected. The remaining Higher notes were not re-read in this pass.
- This pass rewrote 376 of the 707 Foundation notes (155 that had been reduced to a pointer, 221 that carried placeholder wording, 0 overlap), and 55 Higher notes. All were written from the scheme entry for the cited question, in own words, with no figures.
- Thin Foundation notes: 58 more multi-mark Foundation notes that had been fragments (for example only "accuracy mark for the correct value") were rewritten from their scheme entries in a second pass. Of the 114 written notes with 2 or more marks under 110 characters, these 58 (plus jun2024-3f-15 and nov2020-1f-17, re-read in full and rewritten to cover every mark condition) were the ones lacking task context; the other 56 already state the mark structure and were left. The 593 remaining written notes were not re-read in this pass.
- One-mark notes with an "other numbers" restriction were reworded to say what the question asked (for example jun2019-1f-4).
- nov2022-1h-12: the scheme (November 2022 1H, PDF page 10) says trial and improvement scores no marks unless both values are correct. It does not refer to jun2024-1h-10; the earlier inferred link was removed.
- Template docs (TEMPLATES.md, FOUNDATION-TEMPLATES.md): every example line now uses the question's current method note, so the docs and JSON match.
- A few notes end with "see the cited scheme file and page" where only part of a multi-part entry was summarised (for example nov2023-3h-18, jun2023-2h-5, jun2024-2h-14, jun2022-1h-15, jun2025-2h-23, jun2019-2h-14 part b).
