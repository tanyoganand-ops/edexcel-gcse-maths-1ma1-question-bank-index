# Answer templates (Foundation), by pattern

How to read this. Each pattern has: when it appears, a set-out skeleton (this project's own teaching advice, not Pearson wording), what each example scheme awards (described in our own words, with scheme file and PDF page), and "seen in" counts from our data (two kinds, defined next).

Evidence status: marking lines describe only the listed example schemes (scheme file, printed PDF page) and are not general rules; other questions in the pattern may differ. No Foundation examiner report was found, so there are no examiner claims and no "common errors" evidence. All skeleton advice is UNVERIFIED teaching advice from this project.

Seen-in counts come in two kinds. The pattern count requires a primary topic in the pattern's topic codes and a keyword match in the question wording (a heuristic, not a read of each question). The topic count is only the number of questions with those primary topics.

## Averages and the range

- Seen in: 27 questions with a primary topic in S01 and wording that matches the pattern keywords (heuristic, may include a few false matches and miss some); 31 questions have one of those primary topics (topic count, not a pattern count).
- When it appears: Mean from a list or frequency table, a missing value, or a comparison of two lists.
- Teaching advice (ours, set-out skeleton): Mean: 1 Add all the values (or multiply each value by its frequency and add). 2 Divide by the count (or total frequency). 3 For a missing value, total = mean x count, then subtract the known values. Median: 1 Put the values in order. 2 Take the middle one, or the mean of the middle two. 3 For a frequency table, find the position (n+1)/2 first. Mode: the most common value, or the class with the highest frequency. Range: largest minus smallest (a single number). For a comparison write one fact about an average and one about the spread.
